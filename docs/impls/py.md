## Install

```sh
pip install libbtcr2@git+https://github.com/dcdpr/did-btcr2-py
```

From source:

```sh
git clone https://github.com/dcdpr/did-btcr2-py.git
cd did-btcr2-py
python -m venv venv
source venv/bin/activate   # Windows: .\venv\Scripts\activate
pip install -r requirements.txt
```
