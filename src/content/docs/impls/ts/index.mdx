The SDK and the CLI are ready to use. The packages are 0.x, so a minor release
(for example 0.27 to 0.28) can contain breaking changes. Read the changelog of
the package before a minor bump.
:::

## Packages

Start with the SDK or the CLI. They include the lower-level packages.

| Package | Purpose |
|---|---|
| [`@did-btcr2/api`](https://www.npmjs.com/package/@did-btcr2/api) | The SDK. One facade for the DID operations, the Bitcoin connection, key management, and the CAS. It re-exports the key pair, signer, and genesis document helpers. |
| [`@did-btcr2/cli`](https://www.npmjs.com/package/@did-btcr2/cli) | The `btcr2` command. It wraps the SDK and adds an encrypted keystore and config profiles. |
| [`@did-btcr2/method`](https://www.npmjs.com/package/@did-btcr2/method) | The sans-I/O DID Method: identifiers, beacons, and the Resolver and Updater state machines. Use it to customize the protocol. |
| [`@did-btcr2/aggregation`](https://www.npmjs.com/package/@did-btcr2/aggregation) | Multi-party aggregate beacons (CAS and SMT) with MuSig2, over Nostr or HTTP transports. |
| [`@did-btcr2/bitcoin`](https://www.npmjs.com/package/@did-btcr2/bitcoin) | Bitcoin Esplora REST and Bitcoin Core RPC clients with a pluggable HTTP executor. |
| [`@did-btcr2/keypair`](https://www.npmjs.com/package/@did-btcr2/keypair) | secp256k1 key pairs, Multikey encoding, and the `Signer` interface (`LocalSigner`). |
| [`@did-btcr2/key-manager`](https://www.npmjs.com/package/@did-btcr2/key-manager) | Key management: generate, import, sign, and verify, with URN key ids. |
| [`@did-btcr2/cryptosuite`](https://www.npmjs.com/package/@did-btcr2/cryptosuite) | The `bip340-jcs-2025` Data Integrity cryptosuite. |
| [`@did-btcr2/common`](https://www.npmjs.com/package/@did-btcr2/common) | Shared types, errors, JCS canonicalization, and hashing. |
| [`@did-btcr2/smt`](https://www.npmjs.com/package/@did-btcr2/smt) | The optimized Sparse Merkle Tree of SMT beacons. |

## Runtime

* Node.js 22 or newer.
* Browsers: `@did-btcr2/api`, `@did-btcr2/method`, and `@did-btcr2/aggregation`
  ship a prebuilt browser bundle through the `browser` export condition. Public
  endpoints need a small setup: see [Use in a browser](/impls/ts/sdk/#use-in-a-browser).
* The packages are pure JavaScript (no WASM). Each package ships ESM and CJS.

## Contributing

To report bugs or request features, open an issue at
[github.com/dcdpr/did-btcr2-js/issues](https://github.com/dcdpr/did-btcr2-js/issues).

Local development:

```sh
git clone https://github.com/dcdpr/did-btcr2-js.git
cd did-btcr2-js
pnpm install
pnpm build
pnpm build:tests
pnpm test
```

The contributor docs (architecture and ADRs) are in the
[`docs/`](https://github.com/dcdpr/did-btcr2-js/tree/main/docs) directory of the
monorepo. `pnpm docs:build` builds them together with the API reference.
